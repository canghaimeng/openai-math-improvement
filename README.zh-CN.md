**20题测试 · 8项改进 · 3项社区领先结果**

我们用 **[Euler](https://github.com/canghaimeng/Euler)** 对 OpenAI 数学成果库中的20个问题开展测试。由公开可用模型组成的团队，在 **8个问题**上获得了优于原始公开结果的界。**其中3项超过了我们在2026年10月17日至19日核对的社区公开最好结果。**

这些成果展示了 Euler 的共享研究状态与智能体团队协作如何帮助公开可用的模型，在具体数学问题上超越 OpenAI 内部研究模型已经公开的结果。其中，精确傅里叶变换的改进还配有完整 Lean 形式化证明。

Euler 将团队的探索组织为共享的数学研究状态。模型可以接续彼此的论证、追踪证明依赖、保留有价值的失败尝试，并将命题提交独立验证。研究者可以跟踪持续更新的证明图，也可以从保存的研究状态出发，引导团队继续探索。

## 数学成果

**平均推理时间：每题86分钟。**

| 问题 | Euler 团队取得的结果 | 推理时间 | 论文与思路 |
| --- | --- | --- | --- |
| **精确离散傅里叶变换** ⭐ | 指数节省达到 **63/50000 = 0.00126**，优于原始任意长度结果的 **10⁻¹³**。附完整 Lean 形式化。 | 3小时27分 | [阅读 →](problems/bound-130/) |
| **正四面体的圆柱覆盖** ⭐ | 使用 **20,000根圆柱**，底面积总和小于 OpenAI 展示的 **16,000,000根圆柱**构造。 | 1小时26分 | [阅读 →](problems/bound-100/) |
| **球面 Laughlin 谱隙** ⭐ | 对充分大的系统，给出精确下界 **0.21901701265**，超过原始统一下界 **1/25** 的 **5.47倍**。 | 2小时1分 | [阅读 →](problems/bound-269/) |
| **图的 switch chain 混合时间** | 在相同的四顶点提议链下，将混合时间上界从 **2n⁸** 改进为 **n⁶**。 | 35分 | [阅读 →](problems/bound-131/) |
| **平均敏感度** | 将 `AS(f) ≤ C d√n` 中的统一系数从 OpenAI 的 **8** 改进为 **3.192**。 | 2小时22分 | [阅读 →](problems/bound-127/) |
| **单样本拟阵 prophet 不等式** | 在对手可观察全部随机种子的模型中，给出超过原始 **2⁻²⁹³** 的显式有理竞争比。 | 43分 | [阅读 →](problems/bound-111/) |
| **敏感度与块敏感度分离** | 得到显式分离指数 **α > 2.032083**，改进原始展示构造。 | 20分 | [阅读 →](problems/bound-132/) |
| **Heilbronn 三角形问题** | 对每个充分大的 `n`，在面积下界 `c n^(-2+η)` 中给出显式指数增量 **η = 2/100866719**。 | 38分 | [阅读 →](problems/bound-191/) |

⭐ **社区领先：**这三项结果超过了2026年10月17日至19日比对中核对的、可直接比较的社区公开最好界。

每篇论文均给出数学模型、假设、构造和证明，并注明原始工作及后续贡献的来源。这些成果在已有研究的基础上取得了表中所示的进展。

### 一项完整的形式化成果

精确 DFT 定理附有 [Lean 源码](problems/bound-130/lean/)，并已通过 [Big O Speedrun](https://github.com/bigospeedrun/verifier/issues/16#issuecomment-6240050032) 的 **Lean 与 nanoda 验证**。

```math
T(n)=O\!\left(n(\log n)^{1-63/50000}\right).
```
