# A uniform average-sensitivity bound

Developed with [Euler](https://github.com/canghaimeng/Euler), a mathematical research system for collaborative reasoning and human-guided exploration.

**[Read the paper](paper.pdf)**

For every degree-at-most-`d` polynomial threshold function on the uniform sign cube in `n` variables,

$$\operatorname{AS}(f)\le\frac{399}{125}d\sqrt n=3.192d\sqrt n.$$

This improves OpenAI's original coefficient **8** for every dimension and degree. The paper gives a self-contained proof using OpenAI's weighted filtration and parity reductions together with the compensated coupling of Lagdive, Aglave and Damre. An exact rational certificate supplies the displayed constant.
