# An exact spherical Laughlin gap certificate

Developed with [Euler](https://github.com/canghaimeng/Euler), a mathematical research system for collaborative reasoning and human-guided exploration.

**[Read the paper](paper.pdf)**

For the unperturbed spherical fermionic `V₁` Hamiltonian, with coefficient one per pair projector and flux `Q=3(N−1)`, we obtain the eventual uniform gap bound

$$\gamma=\frac{4380340253}{20000000000}=0.21901701265.$$

This is over **5.47 times** OpenAI's original uniform bound **1/25**. The theorem holds for all sufficiently large particle numbers.

The proof combines OpenAI's Fock-space comparison with Qiang Gao's enlarged certificate and tail estimates, then adjusts the certificate by an exact rational multiplier. The complete certificate is included in the paper's mathematical supplement.
