# An improved exponent for Heilbronn triangles

Developed with [Euler](https://github.com/canghaimeng/Euler), a mathematical research system for collaborative reasoning and human-guided exploration.

**[Read the paper](paper.pdf)**

For every sufficiently large integer `n`, we construct `n` points in the unit square whose smallest triangle area is at least

$$c\,n^{-2+\eta},\qquad \eta=\frac{2}{100866719}.$$

The exponent improves the original OpenAI construction. The proof refines the lift-box scale in the projective lattice framework, using Blinov's degree-five norm decomposition, reserved labels and slab estimate. The paper supplies the digit moments, singular determinant bounds, deletion argument, and transfer to every sufficiently large cardinality, with explicit constants.
