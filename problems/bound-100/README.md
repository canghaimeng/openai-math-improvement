# A smaller 20,000-cylinder tetrahedron cover

Developed with [Euler](https://github.com/canghaimeng/Euler), a mathematical research system for collaborative reasoning and human-guided exploration.

**[Read the paper](paper.pdf)**

We cover the entire closed regular tetrahedron using **20,000 cylinders**, with normalized total perpendicular-base area **below 0.4999213**. OpenAI's displayed angular construction uses **16,000,000 cylinders** and has larger area.

The construction chooses the rational parameter `e=13/125` in the compatible-secant family, proves coverage throughout the required parameter range, and bounds the finite area with exact arithmetic. It builds on OpenAI's angular construction and van de Kamp's quartic overlap and padding estimates.
